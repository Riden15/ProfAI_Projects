# ProfAI_Projects

Repository che raccoglie i progetti sviluppati durante il master.

## Progetti

- **Python_advance**: sistema di sincronizzazione di file tra due cartelle (caso d'uso *SyncEase*), con hash MD5, multiprocessing (`ProcessPoolExecutor`) e multithreading (`ThreadPoolExecutor`), più un ambiente di test dedicato.
- **SQL**: esercizi e progetti su database relazionali e NoSQL (SQL e MongoDB), con specifiche e file di supporto.
- **Search_Engine_Optimization**: progetto finale con notebook e materiali su tematiche di SEO e metriche di similarità testuale.
- **Language_Identification**: studio e sperimentazione di modelli per il riconoscimento automatico della lingua, con notebook di analisi e una API (`src/`) con relativi test (`tests/`). Vedi il [README](Language_Identification/README.md) del progetto.
- **RAG**: progetto su Retrieval-Augmented Generation con analisi di documenti locali e notebook di sperimentazione.
- **Pytorch**: ottimizzazione di una rete neurale per la classificazione di immagini di cibo (14 categorie) con data augmentation e transfer learning (VGG19 e ResNet152). Vedi il [README](Pytorch/README.md) del progetto.
- **Agentic_AI**: agente AI per la gestione del rischio finanziario e audit interattivi (caso *FinSecure Analytics*), costruito con LlamaIndex (indice vettoriale sui documenti) e LangChain (agente ReAct con memoria e 4 tool: ricerca nei documenti, calcolo KPI, simulazione di scenari, audit di documento).
